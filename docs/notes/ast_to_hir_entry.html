전체 호출 체인 (AST → HIR)

러스트 컴파일러는 파싱 후 AST를 HIR로 변환한다. 이 변환은 쿼리 시스템에 의해 HIR owner(LocalDefId) 단위로 게으르게(lazy) 수행된다. 진입 쿼리는 lower_to_hir이며, 아래 코드에서 그 구현을 따라간다.

  └ provider lower_to_hir              lib.rs:102 (provide), impl lib.rs:656
       ├ tcx.index_ast(()) → AstOwner  index.rs (AST 노드 → owner 매핑)

           Crate(c)   → ItemLowerer::lower_crate(&c)    item.rs:72
           Item(i)    → ItemLowerer::lower_item(&i)     item.rs:82
           TraitItem  → lower_trait_item                item.rs:86
           ImplItem   → lower_impl_item                 item.rs:90
           ForeignItem→ lower_foreign_item               item.rs:94
hir_owner provider                        hir/mod.rs:458 → tcx.lower_to_hir(def_id)

lower_to_hir 이후의 내부 흐름

디스패치된 각 메서드는 동일한 LoweringContext 위에서 실제 AST 노드를 순회하며 HIR을 빌드한다.

핵심 포인트

  • Lazy per-owner lowering — 전체 크레이트를 한 번에 내리는 게 아니라, HIR 노드가 필요해질 때마다 해당 LocalDefId에 대해 쿼리가 실행된다.
  • AstOwner 인덱스 — index_ast가 AST 노드 ID를 HIR owner로 매핑하며, AST에 없는 중첩 정의(enum variant field 등)는 fallback_to_ancestor로 부모 owner에서 가져온다.
  • arena 할당 — 모든 HIR 노드는 lctx.arena에 할당되어 수명을 'hir로 묶는다.
